# guessing_game

guessing_game built with bash

## Problem_Statement​

There is this guessing game from day 3 and the whole batch has been playing it. Now the players are asking for more. Those who have experience are bored and want a harder game, while the beginners want an easier one. The leaderboard is unfair: one player can fill all five places. One player wants to start again with a clean record. And last week someone edited the games file by hand and broke it. This weekend you ship the version that fixes all of that.

## 📌 Project Goals​

- Highlight the differnt levels of the game
- Names of the players
- The number of attempts form the different levels from different players.
- Indicate when the players guess right
